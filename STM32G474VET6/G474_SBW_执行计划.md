# STM32G474VET6 端 SBW 执行计划

> 角色：执行与反馈层 ECU  
> 目标：接收 S32K144 的目标档位，驱动舵机完成换挡执行，回传实际档位和状态  
> 对应总规划：P3 G474 执行层开发与联调阶段  
> **通信策略**：当前使用 FDCAN2 Classic CAN 500kbps 与 S32K144 通信；FDCAN1 保留为后期 CAN FD 升级。

---

## 1. 硬件定位

G474 作为 **执行 + 反馈层**：
- 只通过 **FDCAN2（Classic CAN 500kbps）** 接收 S32K144 发送的 target_gear，不处理 P 键/解锁键等驾驶员输入
- 驱动舵机到对应档位位置
- 读取位置传感器/舵机反馈，确认实际档位
- 周期性回传 0x280 报文给 S32K144
- **FDCAN1 保留**：用于后期 CAN FD 主通信升级（当前 TJA1050 收发器不支持 FD）

---

## 2. 需配置外设

| 外设 | 用途 | 配置要点 |
|---|---|---|
| FDCAN2 | 与 S32K144 CAN2 通信（当前 Classic CAN） | 500kbps，CAN ID 0x180/0x280；主频 80MHz |
| FDCAN1 | 保留为后期 CAN FD 主通信 | 暂不启用，需配套 CAN FD 收发器 |
| PWM（TIM） | 舵机角度控制 | 50Hz，脉宽 0.5ms~2.5ms 对应 0°~180° |
| GPIO | 档位位置传感器/限位开关输入、LED 指示灯 | 输入模式，可配置上拉 |
| ADC | 位置传感器模拟量采集（如电位器反馈） | 用于校验舵机实际位置 |
| UART | 调试打印 | 115200-8-N-1 |
| FreeRTOS | 多任务调度 | 任务周期 10ms |

> **说明：PB0/PB1 等按键已移到 S32K144 处理，G474 不再采集按键。**

---

## 3. 任务划分（FreeRTOS）

| 任务名 | 周期 | 职责 |
|---|---|---|
| `vTask_CAN_Rx` | 事件触发 | 接收 0x180 目标档位报文，更新 target_gear |
| `vTask_Servo_Control` | 10ms | 根据 target_gear 计算舵机目标角度，输出 PWM |
| `vTask_Position_Feedback` | 10ms | 读取位置传感器，判断 actual_gear |
| `vTask_CAN_Tx` | 10ms | 打包 0x280 报文，回传 actual_gear + 状态 |
| `vTask_Debug` | 100ms | UART 打印目标档、实际档、舵机角度、故障码 |

## 4. 舵机换挡执行方案

### 4.1 舵机选型要求
- 角度范围：0° ~ 180°
- 控制信号：PWM 50Hz
- 脉宽映射：
  - 0.5ms → 0°
  - 1.5ms → 90°
  - 2.5ms → 180°

### 4.2 档位-角度映射表

| 档位 | 舵机角度 | 说明 |
|---|---|---|
| P | 0° | 驻车锁止 |
| R | 36° | 倒档 |
| N | 72° | 空档 |
| D | 108° | 前进档 |
| M（共用 D 机械位置）| 108° | 手动模式与 D 同机械位置 |

> 注：若采用 5 档机械结构（P/R/N/D/M 机械分离），角度按实际槽位均匀分配。

### 4.3 运动控制
- 收到 target_gear 变化时，按固定速率移动到目标角度（防止机械冲击）
- 移动过程中 actual_gear = 上一次稳定档位
- 到达目标角度附近（±3°）且稳定 100ms 后，actual_gear = target_gear

---

## 5. CAN 报文定义（Classic CAN 500kbps）

### 5.1 接收：0x180 目标档位 / 控制指令

| 字节 | 信号 | 说明 |
|---|---|---|
| Byte0 | target_gear | 目标档位：P=0, R=1, N=2, D=3, M1~M6=11~16, FAULT=255 |
| Byte1 | gear_display | 仪表显示档位 |
| Byte2 | reserved | 保留 |
| Byte3 | life_counter | 生命帧计数，用于判断通信是否中断 |
| Byte4-7 | reserved | 保留 |

### 5.2 发送：0x280 实际档位 / 状态反馈

| 字节 | 信号 | 说明 |
|---|---|---|
| Byte0 | actual_gear | 实际档位，编码同 target_gear |
| Byte1 | servo_angle | 舵机当前角度（0~180） |
| Byte2 | status | Bit0: 执行中；Bit1: 到位；Bit2: 故障 |
| Byte3 | life_counter | 回传生命帧 |
| Byte4-7 | reserved | 保留 |

## 7. 安全保护

### 7.1 通信超时保护
- 超过 500ms 未收到 0x180，判定为通信中断
- G474 进入 fail-safe：保持当前 actual_gear，舵机停止响应新的 target_gear
- 0x280 的 status bit0 置 1，标识通信超时故障

### 7.2 通信自动恢复
- 通信中断期间，G474 持续监听 0x180
- 一旦重新收到合法的 0x180，自动清除超时标志，退出保护状态
- 恢复后按新的 target_gear 正常执行换挡

### 7.3 主从 ECU 复位同步
- S32K144 复位重启后默认档位可能与 G474 实际档位不一致
- 推荐策略：S32K144 上电后先读取 G474 回传的 actual_gear，再决定 target_gear
- 或直接约定上电默认进入 N 挡，双 ECU 同步后再响应驾驶员输入

### 7.4 其他保护
- **目标档合法性检查**：只接受 0/1/2/3/11~16/255，非法值保持上一档
- **机械限位**：舵机角度限制在 0°~180°
- **移动超时保护**：档位切换超过 1s 未到位，置执行故障

## 8. 验收标准

- [ ] 舵机能根据 CAN 指令准确到达各档位位置
- [ ] 0x280 报文每 10ms 发送，actual_gear 与机械位置一致
- [ ] 双 ECU 联调时换挡动作与 S32K144 决策同步
- [ ] 通信中断时舵机保持当前档并上报故障
- [ ] 通信恢复后自动退出保护状态，不出现异常跳挡
- [ ] S32K144 复位后能与 G474 实际档位重新同步
- [ ] 串口调试信息完整可读
