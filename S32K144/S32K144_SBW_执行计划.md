# S32K144 端 SBW 执行计划

> 角色：采集与决策层 ECU  
> 目标：采集摇杆/刹车/车速等输入，运行 Stateflow 生成的换挡逻辑，通过 CAN 向 G474 发送目标档位  
> 对应总规划：P2 S32K144 闭环测试阶段  
> **通信策略**：当前使用 CAN2 Classic CAN 500kbps 与 G474 通信；CAN0 保留为后期 CAN FD 升级。

---

## 1. 硬件定位

S32K144 作为 **集成采集 + 决策层**：
- 负责读取 P 键/解锁键等所有驾驶员输入
- 开发板上直接集成两个电位器，适合采集 stick_x / stick_y（摇杆模拟量）
- 运行 MATLAB/Simulink 生成的 Stateflow C 代码进行换挡决策
- 通过 **CAN2（Classic CAN 500kbps）** 将目标档位发送给 G474 执行层
- **CAN0 保留**：S32K144 仅 CAN0 支持 CAN FD，启用 FD 后 CAN1/CAN2 不可用，故当前不启用

---

## 2. 需配置外设

| 外设 | 用途 | 配置要点 |
|---|---|---|
| ADC（ADC0/ADC1） | 采集 stick_x、stick_y、brake_pedal 等电位器信号 | 12bit、软件触发、轮询或 DMA |
| GPIO | **P 档按键、解锁按键**、valid 等数字输入；LED 状态指示 | 上拉/下拉根据硬件确定 |
| CAN2（FlexCAN） | 与 G474 FDCAN2 通信（当前 Classic CAN） | 500kbps；引脚 PTC16/RX、PTC17/TX |
| CAN0（FlexCAN） | 保留为后期 CAN FD 主通信 | 暂不启用，启用 FD 后 CAN1/CAN2 不可用 |
| UART（LPUART） | 调试打印、标定 | 115200-8-N-1 |
| FreeRTOS | 多任务调度 | 任务周期 10ms |

---

## 3. 任务划分（FreeRTOS）

| 任务名 | 周期 | 职责 |
|---|---|---|
| `vTask_ADC_Sample` | 10ms | 采集所有 ADC 通道，滤波/量化成 stick_x、stick_y、brake_pedal |
| `vTask_Gear_Logic` | 10ms | 调用 `GearShift_Stateflow_step()`，输出 current_gear |
| `vTask_CAN_Tx` | 10ms | 打包 0x180 报文（目标档位 + 控制字），经 CAN2 发送 |
| `vTask_CAN_Rx` | 事件触发 | 经 CAN2 接收 0x280 报文（实际档位/状态），更新 valid 标志 |
| `vTask_Debug` | 100ms | 通过 UART 输出当前档位、输入状态、故障码 |

## 4. 移植 MATLAB 生成代码

### 4.1 拷贝文件
将以下文件从 `MATLAB/GearShift_Stateflow_ert_rtw/` 拷贝到 S32K144 工程：

```
GearShift_Stateflow.c
GearShift_Stateflow.h
GearShift_Stateflow_data.c
GearShift_Stateflow_private.h
GearShift_Stateflow_types.h
rtwtypes.h
```

### 4.2 集成要点
- 在 FreeRTOS 任务中周期性调用 `GearShift_Stateflow_step()`
- 将 ADC/GPIO 采集结果赋值给 `GearShift_Stateflow_U` 结构体：
  - `GearShift_Stateflow_U.stick_x`、`stick_y`
  - `brake_pedal`、`vehicle_speed`、`engine_rpm`
  - `p_button`、`unlock_button`、`valid`
- 从 `GearShift_Stateflow_Y` 读取 `current_gear`、`gear_display`
- 注意：`comm_timeout_timer` 已在 Stateflow 内部维护，S32K144 只需保证 `valid` 由 CAN 接收状态更新

### 4.3 数据映射

| 物理输入 | 来源 | Stateflow 输入 | 类型 | 说明 |
|---|---|---|---|---|
| 摇杆 X 轴 | ADC0 | stick_x | uint8_T | 0=中位，1=前推，2=后拉 |
| 摇杆 Y 轴 | ADC1 | stick_y | uint8_T | 0=中位，1=左拉，2=右推 |
| 刹车踏板 | ADC2 | brake_pedal | uint8_T | 0~100 百分比 |
| 车速 | 仿真/标定 | vehicle_speed | uint8_T | km/h |
| 发动机转速 | 仿真/标定 | engine_rpm | uint16_T | rpm |
| P 档按键 | GPIO | p_button | boolean | 1=按下 |
| 解锁按键 | GPIO | unlock_button | boolean | 1=按下 |
| G474 在线标志 | CAN2 | valid | boolean | 收到 0x280 后置 1 |

## 5. CAN 报文定义（S32K144 发送，Classic CAN 500kbps）

### 0x180：目标档位 / 控制指令

| 字节 | 信号 | 说明 |
|---|---|---|
| Byte0 | target_gear | 目标档位：P=0, R=1, N=2, D=3, M1~M6=11~16, FAULT=255 |
| Byte1 | gear_display | 仪表显示档位 |
| Byte2 | reserved | 保留 |
| Byte3 | life_counter | 生命帧计数，G474 用于判断通信是否中断 |
| Byte4-7 | reserved | 保留 |
