# 第 9 章：车辆模型与演示调校

## 为什么台架上需要一个车辆模型

真车换挡逻辑依赖三个外部量：**车速、发动机转速、刹车**。台架上没有发动机和变速箱，如果车速恒为 0：

- M 挡永远进不去（升挡要 `speed>=25`）。
- 自动挡的升降挡逻辑（`rpm>6500` 保护）永远不触发。
- 演示时"换到 D 踩油门"没有任何反馈，面试官看不出逻辑在跑。

所以需要一个小型的纵向动力学模型，把"油门百分比"变成"车速和转速"。

## 模型结构（`sbw_veh.c`，375 行）

```
油门% ──(一阶惯性)──► 实际油门 ──► 发动机扭矩曲线(rpm) ──► 驱动力
                                                          │
刹车% ──► 制动力 ─────────────────────────────────────────┤
                                                          ▼
                            ┌───────────────────► 加速度 ──► 速度积分 ──► 车速
                            │                                         │
                 空气阻力 + 滚动阻力                                ▼
                                                          齿比/主减速 → 转速
                                                          │
                              ┌───────────────────────────┘
                              ▼
                        挡位(来自状态机) ──► 齿比选择
```

**单向依赖**：状态机出挡位 → 模型算车速/转速 → 状态机用它们做判断。这个环是闭合的，而且是**物理正确的**：挡位低 → 同车速下转速高 → 更容易触发"超转升挡"。

## 六挡手动变速器齿比

| 挡 | 齿比 | 2000rpm 对应车速 | 6800rpm 对应车速 |
|----|------|------------------|------------------|
| M1 | 3.545 | 17 km/h | 57 km/h |
| M2 | 2.105 | 29 km/h | 97 km/h |
| M3 | 1.357 | 44 km/h | 150 km/h |
| M4 | 1.000 | 60 km/h | 204 km/h |
| M5 | 0.822 | 73 km/h | 248 km/h |
| M6 | 0.685 | 88 km/h | 297 km/h（超出 240 上限） |
| R | 3.545 | — | — |

**换算公式**：

```
rpm = (v / (2πR)) × 60 × ratio × final_drive
    = (v / 1.948) × 60 × ratio × 3.90
```

例：M6、240km/h = 66.7m/s → 轮速 34.2 r/s → 输出轴 34.2×3.90 = 133.4 r/s → 发动机 133.4×0.685 = 91.4 r/s = **5485 rpm**。

> 所以 240km/h 在 6 挡只有 5485rpm，离红线 6800 还有余量——这符合"6 挡是超速挡"的设计。

## 发动机扭矩曲线（8 点线性插值）

| 转速 | 800 | 1200 | 2000 | 3000 | 4000 | 5000 | 6000 | 6800 |
|------|-----|------|------|------|------|------|------|------|
| 系数 | 0.45 | 0.62 | 0.82 | 0.98 | 1.00 | 0.95 | 0.85 | 0.72 |

峰值在 4000rpm，符合自然吸气发动机的特性。乘以 `ENGINE_TORQUE_MAX` 得到实际扭矩，再乘以油门开度。

## 四个特殊工况

### ① 空挡自由转速

车速为 0 或空挡时，转速由油门直接决定：

```
rpm_target = RPM_IDLE + 油门 × (RPM_FUEL_CUT - RPM_IDLE)
```

800 → 6700，模拟"空踩油门轰转速"。

### ② 半联动（起步）

车速低于"该挡的怠速车速"时，发动机不可能被拖到怠速以下（会熄火）。此时：

```
rpm_target = RPM_IDLE + 油门 × RPM_LAUNCH_SPAN
```

即踩油门时转速从 800 升到 3300，给离合器一个滑动窗口。

### ③ 断油保护

`rpm > RPM_FUEL_CUT (6700)` → 扭矩 = 0；降到 `RPM_FUEL_RESUME (6300)` 才恢复。400rpm 的滞回防止在断油点附近抖动。

### ④ 发动机制动

松油门（油门 < 5%）且车速 > 0 时，施加 `ENGINE_BRAKE_TORQUE (28Nm)` 的负扭矩。但**静止时不推车**：

```c
if (speed > 0.1f) { 施加发动机制动 }
```

否则停车挂挡时会闻到"车自己往后溜"的诡异现象。

## 演示调校：为什么车"太冲"

**问题**（用户原话）："车速和转速以及手动档位一点都不好控制。"

原因：真实车辆 0→100km/h 约 10s，但台架上摇杆是数字量，一脚下去油门瞬间 100%，0→25km/h 只要 1s——**M1 升 M2 的门槛（25km/h）一闪而过**，根本来不及操作。

**改法**：

```c
#define THROTTLE_RAMP_PER_S   0.9f    /* 满油门需 1.1s */
static float s_throttle;               /* 实际油门，跟踪 g_throttle_pct */

#define DEMO_INERTIA_SCALE    3.0f    /* 等效质量 4200kg */
/* 积分时用 VEH_MASS_KG * DEMO_INERTIA_SCALE */
```

**为什么放大质量而不是改齿比**：放大质量只减慢**加速度**，稳态极速不变（阻力平衡点还是 240km/h）。改齿比会同时改变极速和转速对应关系，破坏 M 挡门槛的标定。

**效果**：

| 工况 | 改前 | 改后 |
|------|------|------|
| 0→25 km/h | <1s | ~3.5s |
| 0→100 km/h | ~7s | ~18s |
| 240 km/h 能否达到 | 能 | 能（只是更慢） |

两个宏可调：`4.0` 更肉，`2.5` 更冲。

## 挡位编码到模型的映射

```c
switch (gearCode) {
  case 0: case 2: case 255:  ratio = 0;  break;   /* P/N/FAULT → 空挡 */
  case 1:                    ratio = 3.545; break; /* R */
  case 3:                    ratio = 自动挡（2400 升 / 1200 降）; break;
  case 11..16:               ratio = kGearRatio[gearCode - 10]; break;
}
```

**注意 P 和 N 都走空挡齿比**：P 在模型里没有"驻车棘爪"的物理效果（车速不会因挂 P 而锁死）。这是一个简化——台架上的 P 只是舵机角度不同。

## 与状态机门槛的契合度验证

M 挡升挡要求 `rpm>=2000 && speed>=25/50/80/120/160`。用上面的齿比反算：

| 过渡 | 门槛车速 | 该车速下的转速 | 是否满足 rpm≥2000 |
|------|----------|----------------|-------------------|
| M1→M2 | 25 km/h | 2958 | ✅ |
| M2→M3 | 50 km/h | 3512 | ✅ |
| M3→M4 | 80 km/h | 3622 | ✅ |
| M4→M5 | 120 km/h | 3987 | ✅ |
| M5→M6 | 160 km/h | 4380 | ✅ |

全部满足，说明齿比与门槛是**配套标定**过的，不是随手填的。这一条在面试里很加分——它证明你验算过参数一致性，而不是"编译通过就算完"。
